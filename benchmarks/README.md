# Benchmarks

Benchmark scripts for all 40 model configurations evaluated in the ADAB paper.

## Structure

- `traditional_ml/` — Logistic Regression, SVM, XGBoost with TF-IDF, FastText, GloVe, Word2Vec
- `transformers/` — Fine-tuning scripts for AraBERTv02, MARBERT, CAMeLBERT-mix, XLM-RoBERTa, mDeBERTa, RemBERT, InfoXLM, mBERT
- `llms/` — Zero-shot and few-shot prompting scripts for GPT-4 mini, Claude Sonnet 4.5, DeepSeek V3, GPT OSS 20B, Fanar-1-9B, ALLaM-7B

Scripts will be released alongside the dataset upon paper acceptance.
