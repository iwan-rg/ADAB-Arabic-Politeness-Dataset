# Dataset

The ADAB dataset files will be released here upon paper acceptance at LREC-COLING 2026.

Expected files:
- `adab_dataset.csv` — full 10,000-text annotated dataset
- `adab_train.csv` — training split
- `adab_dev.csv` — development split
- `adab_test.csv` — test split

Each file will include columns for: `text`, `label` (polite/neutral/impolite), `dialect`, `source`, and `categories`.
